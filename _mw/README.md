# stratbox engineering workspace

`_mw/` — инженерное рабочее пространство `stratbox`. Здесь живут Research, исходные материалы, история и будущие Work-артефакты, которым требуется отдельный от продукта жизненный цикл.

Главная точка входа — `_mw/AGENTS.md`. Этот файл является паспортом рабочего пространства и содержит его текущую архитектуру.

## Текущая структура

```text
_mw/
├── AGENTS.md
├── README.md
└── epochs-001-core-development/
    └── research/
        ├── 01-old-notes/
        │   └── README.md
        └── 02-base-study/
            └── README.md
```

`epochs-001-core-development` — единственная активная эпоха.

- `01-old-notes` принимает и сохраняет исторические заметки и прежние материалы как provenance.
- `02-base-study` предназначена для свежего исследования фактического состояния текущего репозитория.

Новые каталоги добавляются только когда появляется реальная отдельная ответственность, потребитель или жизненный цикл. Пустой каркас будущих стадий заранее не создаётся.
