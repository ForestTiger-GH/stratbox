# Strategy Box — continuous knowledge consolidation

**Posture:** PREPARED / NOT STARTED. Эта поверхность — отдельный рабочий контур единой консолидации; исследовательские ветки `research/01–03` остаются историческими Research, а `docs/` предназначен для поддерживаемого продукта знаний.

## Cold entry — следующий агент

1. Прочитать корневые `AGENTS.md`, `README.md`, `_mw/AGENTS.md` и настоящий README.
2. Прочитать [CYCLE.md](CYCLE.md), [METHOD-ROUTER.md](METHOD-ROUTER.md), [sources/CENSUS.csv](sources/CENSUS.csv), [STATE.md](STATE.md), [BASELINE.md](BASELINE.md), [ARCHITECTURE.md](ARCHITECTURE.md) и [sources/SEED.md](sources/SEED.md).
3. Проверить актуальную Human Commission, Git HEAD и доступ к прямым implementation owners.
4. Прочитать точные Research-ветки и проверяемые первичные источники по зафиксированному source universe.
5. В рамках отдельного поручения на полный цикл выполнять стадии без искусственных пауз; после каждого законченного блока обновлять проверяемое состояние.

Полный file-level реестр двух основных репозиториев уже составлен: 553 SHA-проверенные строки (`stratbox`: 338, `stratbox-windows`: 198, выбранные контракты AppDock: 17). Все material units в нём ещё `unaccounted`. Следующий цикл расширяет declared universe для полученных от пользователя и других оправданных источников, а не удаляет пригодный census.

Текущая подготовка **не запускает** сборку, не утверждает WHAT/HOW и не изменяет бизнес-логику. Следующий агент может начать непрерывное исполнение после отдельного человеческого поручения.

## Семантические владельцы

- `BASELINE.md` — версия и границы корпуса для следующего запуска;
- `ARCHITECTURE.md` — рабочий контракт Knowledge Product Architecture;
- `CYCLE.md` — локальный Work Program, сохранение значимого смысла, разрешённые эффекты и gates;
- `METHOD-ROUTER.md` — точные маршруты MADARAII/EXAMPLES, reset и rehydration;
- `STATE.md` — единственная точка продолжения и учёт стадий;
- `sources/CENSUS.csv` — существующий пофайловый census; source-use и material-unit accounting ещё предстоят;
- `docs/` — поддерживаемый, читаемый результат после проверки и принятия.

Новые `units/`, `coverage/`, `reconciliation/`, `questions/`, `gates/` и `late-inputs/` создавать по мере реального заполнения. Не плодить пустые каталоги и дублирующие текущие статусы.

**Граница публикации:** прямые ссылки на MADARAII разрешены только как инструкции выполнения в `METHOD-ROUTER.md`; в `docs/` их не размещать. Общие инженерные принципы и положения использовать полностью. Прежние исследования в `research/` сохранять без зачистки. Детали закрытых расширений не переносить в публичные тексты.
