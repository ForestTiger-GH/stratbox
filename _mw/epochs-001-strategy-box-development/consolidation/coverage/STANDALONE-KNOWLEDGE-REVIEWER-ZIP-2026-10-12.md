# Standalone Knowledge-only reviewer delivery bundle

**Intent:** provide a concrete, testable publication surface that remains meaningful when the entire original Research, Work and `docs_old` archive disappears. Run `python3 tools/package_standalone_knowledge.py` from the consolidation workspace or through the repository knowledge evidence workflow.

**Output:** deterministic `dist/strategy-box-knowledge-standalone.zip` and SHA-256 `dist/strategy-box-knowledge-standalone.sha256`. The ZIP contains **only maintained `docs/` bytes** and one root `KNOWLEDGE-HASHES.json` with each file's digest, current Git publication commit and qualified status. No Research/Work, source code, developer secrets, historical original texts, generated local state, or nonpublic component material enters the bundle. The reproducible ZIP uses fixed timestamps/modes and sorted names, is unpacked into a temporary directory, then re-read and validated for exact content hashes, in-root Markdown navigation, source-history backlinks and missing targets. This is a **physical archive deletion rehearsal**, not merely a link scan.

**Delivery:** GitHub Actions uploads the two files as a 14-day expiring artifact named `strategy-box-knowledge-standalone` using the official pinned `actions/upload-artifact` action. Publication snapshot `git_commit` and complete `files_sha256` inside ZIP make each bundle independently identifiable. The CI workflow's subsequent source-original Work steps continue to operate only in the checkout, outside the package.

**Independent reviewer protocol remains OPEN:** give a competent reviewer the ZIP, the separately frozen fourteen user-case questions without producer answer notes and the instruction to answer only from published Knowledge, with exact paths and admitted UNKNOWNs. Record reviewer identity, setup, answers, contradictions and no-Research-access evidence before an original-source reverse audit by a genuinely independent separate reader. The act of packaging, self-testing or self-answering is **not** such a reviewer, cannot mark any census row `verified`, cannot restore owner-declared lost DOCX and cannot claim global semantic `LOSSLESS_PASS`. The absent deployed host and future-client security tests are separate product gates.
