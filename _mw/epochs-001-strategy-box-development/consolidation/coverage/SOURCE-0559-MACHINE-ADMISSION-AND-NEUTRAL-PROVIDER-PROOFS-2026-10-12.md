## 2. Machine LCD regression found and corrected

The previous `docs/lcd/capabilities/curated-machine-operation-adapter-construction.md` defined `MachineAdmission(run_ref, accepted: bool, safe_code)`. A host admission result that was lost after the host may have committed could not be distinguished from definite denial with no Run. A caller could therefore treat an exception as a safe opportunity to submit a new effect with a new identity. This **conflicted with the original machine-interface Research** while the scientific narrative remained correct.

A documented `AdmissionStatus` now distinguishes `ACCEPTED`, `REJECTED` and `OUTCOME_UNKNOWN`. Its `MachineGateway.invoke()` maps a host admission exception to UNKNOWN rather than REJECTED, and rejects malformed/contradictory host port responses as UNKNOWN (accepted without `run_ref`; rejected while carrying `run_ref`; unsupported enum/empty response). Rejected catalog/schema/binding/permission checks still give ordinary REJECTED **before** any host admission call. Idempotency, canonical normalized parameter digest, principal authority and all effects remain **host-owned** and unresolved for production; the gateway cannot guarantee exactly-once physical mutation.

## 3. Generic public-neutral provider false-readiness correction

The separate generic `docs/lcd/extensions/neutral-provider-binding-construction.md` originally forwarded `HealthPort.check()` return values directly into `BindingResult.status` and labeled every result `BOUND_WITH_CHECK`. An erroneous truthy Boolean or string `"ready"` could masquerade as a typed provider readiness state. The candidate `NeutralProviderResolver` now verifies an actual `BindingStatus`, preserves `DEGRADED/UNAVAILABLE/CONFIGURATION_REQUIRED` as distinct non-ready statuses and refuses a descriptor marked `requires_configuration` when configuration is wholly absent. A nonempty configuration still requires a **trusted schema validator** and appropriate scope; health is not permission to invoke, proof of source contents or a sandbox guarantee. Duplicate ID, explicit choice and major-version rules remain scoped to this public generic model.
