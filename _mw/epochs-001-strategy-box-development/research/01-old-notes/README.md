# 01-old-notes

## Role

Историческая Research-ветка первой эпохи для прежних заметок, описаний, ранних исследований и других материалов о Strategy Box, созданных до текущего формального инженерного workspace.

Сюда относятся как прежние материалы по core, так и ранние описания application/interface-слоя. Их совместное хранение отражает историю одного проекта, а не текущую структуру implementation owners.

## Semantics

Материал в этой ветке сохраняется как source/provenance и контекст для последующего анализа.

Размещение здесь не означает, что утверждение:

- соответствует текущему коду;
- принято как текущая архитектура;
- является Product Decision;
- должно быть реализовано.

По возможности сохраняй исходный смысл, дату, происхождение и связь с исходным носителем. Исправления и интерпретации отделяй от самого исторического материала.

## Use

Эта ветка может давать вопросы, гипотезы и направления для `../02-base-study/`. Актуальность значимых утверждений проверяется заново по текущему implementation owner соответствующего компонента и другим релевантным текущим источникам.
