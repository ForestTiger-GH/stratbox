# Патч stratbox Май 2026

## Домен cbr_forms

В stratbox была расширена и унифицирована обработка банковских отчетных форм: добавлена форма 805, а формы 135 и 805 переведены на общий механизм обработки нормативов.

Были расширены модели показателей для форм 135 и 805, включая новые нормативы, а обработка кодов сделана устойчивой к латинице и кириллице, а также к регистру букв.

Была скорректирована логика выгрузки: в таблицах по умолчанию стали использоваться краткие нормализованные наименования банков в CAPS-формате.

Было доработано Excel-оформление выходных таблиц: для числовых значений добавлен разделитель тысячных разрядов.

В целом была усилена общая согласованность контура run all forms: без изменения расчетной логики был улучшен состав форм, формат имен банков и формат представления чисел в итоговых файлах Excel.

## Домен FRG

В stratbox/macrobanks внедрён отдельный доменный пакет для файлов поставщика: сначала как frank_rg, затем переименован в frg.

Реализован stage 1 обработки: чтение папки, распознавание типов файлов по имени, извлечение периода, построение каталога, выбор актуального файла по каждому семейству.

Настроено распознавание месячных, weekly, региональных, карточных, ипотечных, пассивных и Q-файлов.

Добавлена нормализация дат и периодов, включая weekly-формат.

Приведены к удобному виду внутренние family_code и family_name.

Для региональных файлов зафиксирована новая логика: старые схемы после выделения ипотеки отсекаются.

Для weekly-файлов добавлена фильтрация устаревших недель внутри одного месяца.

Введена поддержка двух схем имён: исходные имена поставщика и новые внутренние имена, создаваемые библиотекой.

Настроен приоритет внутреннего имени при дублях одного и того же периода.

Зафиксировано правило: нераспознанные и случайные файлы вообще не трогаются.

Добавлена функция зачистки каталога: копирование или переименование актуальных файлов и удаление только допустимых устаревших.

Добавлено архивирование итогового набора в ZIP-архив FRG_Actuals_YYYY-MM-DD.zip.

Убраны прямые упоминания Frank RG с поверхности кода, документации и API; всё переведено на FRG.

Подготовлены README, документация и примеры запуска для Colab/Jupyter.

Каждое крупное внедрение было проверено на актуальных версиях репозитория.

## Домен escrow

- Добавлен новый домен **macrobanks/escrow** для обработки данных по счетам эскроу.
- Собран полноценный конвейер: **получение ссылок → скачивание исходников → парсинг → long-формат → pivot-таблицы → итоговый Excel/ZIP**.
- Логика сохранения результата посажена на инфраструктуру **Stratbox**: работа через FileStore/ioapi, без прямой завязки на ручные локальные операции.
- Введён **кэш исходных Excel-файлов** через source_cache_dir.
- Добавлен режим сохранения как **обычного .xlsx**, так и **архива .zip**.
- Полностью переработан парсер строк: корректно распознаются **федеральные округа, субъекты РФ и итог по РФ**.
- Сохранён **исходный порядок строк** из файлов ЦБ через display_order.
- Полностью переработан парсер столбцов: сделан **реестр показателей** с устойчивым распознаванием заголовков.
- Зафиксированы **стабильные имена листов Excel** через словарь аббревиатур, чтобы не ломать рабочие ссылки.
- Добавлен новый показатель **КСЭИО** — «Кол-во счетов эскроу, имеющих остатки».
- Учтены исторические варианты заголовков, включая:
  - разные сноски;
  - примечания в скобках;
  - вариант Средняя ставка... вместо Средневзвешенная ставка....
- Учтены исторические варианты итоговой строки:
  - Итого
  - Итого по РФ
  - Итого по Российской Федерации
- Парсер сделан устойчивым к **исторически разным форматам файлов**:
  - старый формат;
  - промежуточный формат;
  - новый формат.
- Известные показатели сделаны **опционально присутствующими по конкретной дате**: отсутствие столбца не валит обработку.
- В итоговой книге сохранён **полный реестр листов**, даже если по части дат некоторые показатели отсутствуют.
- Подготовлена точка расширения под будущий **реестр регионов** (regions_mode='registry' зарезервирован).
- Обновлены экспорт и публичный API: используется **run_escrow_to_xlsx**.
- Добавлены и переработаны **README/документация** по домену escrow.
- Смягчены формулировки в README escrow и связанных описаниях в сторону **корпоративного**, без лишнего акцента на банковый контекст.

## Домен cbr archiver

Добавлен новый домен macrobanks/cbr_archiver для скачивания статистических файлов Банка России.

Реализован отдельный реестр ссылок ЦБ в виде простого плоского списка URL, удобного для ручного пополнения.

Скачивание файлов встроено через существующий сетевой слой stratbox, чтобы работало и снаружи, и внутри банковского контура через шлюз/плагин.

Сохранение результатов реализовано через инфраструктуру FileStore/ioapi, без прямой привязки к локальному диску или Samba.

Добавлены два режима сохранения: пачка исходных файлов в папку и ZIP-архив с исходными файлами.

Для ZIP задано базовое имя CBR Collected Files, с возможностью добавлять дату в название.

Файлы ЦБ сохраняются как есть, без чтения, обработки, изменения структуры или содержимого.

Убрана специальная обработка obs_tabl20с: файл теперь сохраняется с исходным именем, без добавления _new.

Добавлена логика аккуратного именования файлов: имя берется из ответа сервера или URL, дубли безопасно уникализируются.

Добавлена обработка ошибок скачивания: можно продолжать загрузку остальных файлов и получать список неуспешных URL.

Новый домен выведен в публичный импорт через stratbox.macrobanks.

Добавлена документация и пример запуска для Colab и сетевого диска.

Проведена проверка компиляции, импортов, ZIP-режима и сохранения пачки файлов в mock-режиме.
