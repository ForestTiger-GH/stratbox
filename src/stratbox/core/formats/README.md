# Physical format mechanisms

This package reads and writes supported representations while retaining physical
structure, literal values and decoder qualifications. Workbook cells, document
blocks and archive membership are evidence for subsequent interpretation.

Visible [decoding commands](../commands/) invoke these mechanisms. Optional
format dependencies are loaded at the relevant operation. Domain methods select
tables and attach economic meaning to the resulting evidence.

See [processing stages](../../../../docs/current-how/standard-data-stages.md)
and [shared data values](../../shared/data/).
