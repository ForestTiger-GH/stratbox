# Technical execution core

The core executes prepared commands through one bounded service. It owns shared resources, neutral providers, transport and decoding, numerical mechanisms, rendering, storage effects, factual journals and notification handoff. Source interpretation methods arrive already bound to explicit domain settings.

Callable definitions and prepared graph ownership belong to `capabilities`. Pure data and evidence belong to `shared`; applications own deployment, schedules, channels and user interfaces.
