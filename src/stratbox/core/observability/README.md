# Execution facts and observation

The [journal](journal/) is the ordered factual record of command work, logical
scope outcomes, accepted outputs and external effects. Optional observers consume
these facts for application presentation or diagnostics.

Execution facts describe what occurred at each boundary. A completed command,
an accepted analytical value and a confirmed external write carry different
meaning. Source methods return evidence and qualifications through their ports;
they do not deliver notifications.

See [observation boundaries](../../../../docs/architecture/observability.md)
and [notification state](../notifications/).
