# `stratbox.macrobanks.cbr_industries`

Домен для отраслевых таблиц Банка России.

Первая поддерживаемая серия — `01_05_A_Debt_corp` из каталога:

`https://www.cbr.ru/statistics/bank_sector/sors/`

Серия содержит задолженность, включая просроченную, по кредитам юридическим
лицам-резидентам и индивидуальным предпринимателям в региональном разрезе.

## Граница текущей реализации

Реализованы четыре отдельные операции:

1. `discover_cbr_0105a_debt_corp_sources` — найти официальные ссылки выбранного периода;
2. `download_cbr_0105a_debt_corp_sources` — скачать или прочитать из кэша исходные XLSX;
3. `parse_cbr_0105a_debt_corp_downloaded_source` — разобрать одну книгу;
4. `build_cbr_0105a_debt_corp_stream` — собрать единый нормализованный поток.

Экспорт в Excel, pivot-витрины и долговременные производные артефакты в этот этап
не входят.

## Семантика листов

Парсер распознает лист по полному заголовку в `A1`, поэтому изменения пробелов,
запятых и сокращений в имени вкладки не влияют на результат. Поддерживаются шесть
сочетаний:

- задолженность в рублях;
- просроченная задолженность в рублях;
- задолженность в иностранной валюте и драгоценных металлах;
- просроченная задолженность в иностранной валюте и драгоценных металлах;
- задолженность итого;
- просроченная задолженность итого.

## Регионы

В потоке сохраняются два поля:

- `region_source_name` — подпись конкретного исходного файла;
- `region_name` — подпись последней доступной даты выбранного набора.

Так историческое `Кемеровская область` приводится к актуальному для набора
`Кемеровская область - Кузбасс`, при этом исходная подпись остается доступной.
Общий междоменный справочник регионов здесь сознательно не создается.

## Поток

Ключ наблюдения:

```text
report_date + measure + currency_scope + region_code + industry_code
```

Поток содержит экономические измерения, исходные подписи, иерархию отраслей и
provenance до листа и ячейки Excel.
