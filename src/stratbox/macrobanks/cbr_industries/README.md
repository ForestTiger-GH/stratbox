# `stratbox.macrobanks.cbr_industries`

Домен отраслевых таблиц Банка России.

Первая поддерживаемая серия — `01_05_A_Debt_corp` из каталога:

`https://www.cbr.ru/statistics/bank_sector/sors/`

Серия содержит задолженность, включая просроченную, по кредитам юридическим
лицам-резидентам и индивидуальным предпринимателям в региональном разрезе.

## Публичные операции

1. `discover_cbr_0105a_debt_corp_sources` — найти официальные ссылки выбранного периода;
2. `download_cbr_0105a_debt_corp_sources` — скачать или прочитать из кэша исходные XLSX;
3. `parse_cbr_0105a_debt_corp_downloaded_source` — разобрать одну книгу;
4. `build_cbr_0105a_debt_corp_stream` — собрать единый нормализованный поток;
5. `calculate_cbr_0105a_debt_corp_apk_industry` — добавить расчетную отрасль АПК;
6. `build_cbr_0105a_debt_corp_pivot_set` — преобразовать предварительно отфильтрованный поток в набор двумерных таблиц;
7. `save_cbr_0105a_debt_corp_pivot_workbook` — сохранить готовые таблицы отдельными листами одной XLSX-книги;
8. `export_cbr_0105a_debt_corp_industry_workbook` — сформировать CBR-подобную шестилистовую книгу по АПК, опубликованному `ВСЕГО` или иной отрасли.

Предметная фильтрация не встроена в pivot-операцию. Оператор заранее ограничивает
поток, затем назначает измерения строк, столбцов и листов. Все остальные смысловые
измерения должны иметь ровно одно значение, иначе операция возвращает
`Cbr0105ADebtCorpPivotError` с кодом и деталями конфликта.

## Семантика исходных листов

Парсер распознает лист по полному заголовку в `A1`, поэтому изменения пробелов,
запятых и сокращений в имени вкладки не влияют на результат. Поддерживаются шесть
сочетаний:

- задолженность в рублях;
- просроченная задолженность в рублях;
- задолженность в иностранной валюте и драгоценных металлах;
- просроченная задолженность в иностранной валюте и драгоценных металлах;
- задолженность итого;
- просроченная задолженность итого.

## Географический контракт

Серия имеет локальный строгий реестр из 96 географических строк. Проверяются:

- количество строк;
- исходный порядок;
- вид строки;
- известные исторические aliases.

В потоке сохраняются:

- `region_source_name` — подпись конкретного исходного файла;
- `region_name` — конечная подпись локального реестра серии.

Так историческое `Кемеровская область` приводится к
`Кемеровская область - Кузбасс`, при этом исходная подпись остается доступной.
Общий междоменный справочник регионов здесь не создается.

## Поток

Ключ наблюдения:

```text
report_date + measure + currency_scope + region_code + industry_code
```

Поток содержит экономические измерения, исходные подписи, иерархию отраслей и
provenance до листа и ячейки Excel. Месячные части объединяются после выравнивания
категорий, поэтому полный архив не распаковывается во временный тяжелый `object`-
DataFrame.

`Cbr0105ADebtCorpStreamResult.ok` требует одновременно:

- отсутствия ошибок источников;
- отсутствия validation issues уровня `error`.

## Расчетная отрасль АПК

Операция `calculate_cbr_0105a_debt_corp_apk_industry` выполняется после
`build_cbr_0105a_debt_corp_stream` и до предметной фильтрации/pivot. Она
возвращает как строки только по АПК (`df_apk`), так и расширенный поток
(`df_stream`) с дополнительным `industry_code="apk"`.

Расчет выполняется отдельно по каждой дате, географической строке, виду
задолженности и валютному охвату. Сначала рассчитывается ЛПК:

```text
Обработка древесины и производство изделий из дерева
+ Сельское хозяйство, охота и лесное хозяйство
- Сельское хозяйство, охота и предоставление услуг в этих областях
```

Затем АПК рассчитывается как:

```text
Сельское хозяйство, охота и предоставление услуг в этих областях
+ Производство пищевых продуктов, включая напитки, и табака
+ Производство машин и оборудования для сельского и лесного хозяйства
+ ЛПК
```

Функция требует полный набор исходных компонентов для каждой рассчитываемой
комбинации и останавливается с `Cbr0105ADebtCorpDerivedIndustryError`, если
компонент отсутствует, продублирован или уже добавлена отрасль `apk`. Исходные
строки потока не изменяются.

## CBR-подобная книга по одной отрасли

`export_cbr_0105a_debt_corp_industry_workbook` получает уже построенный
`Cbr0105ADebtCorpStreamResult` и формирует динамику выбранного показателя по
регионам. Поток всей истории строится один раз, после чего из него можно
последовательно получить несколько независимых книг.

Специальные коды:

- `industry_code="apk"` — АПК рассчитывается автоматически по формуле домена;
- `industry_code="total"` — используется опубликованная строка ЦБ `ВСЕГО` без
  пересчета;
- любой другой исходный `industry_code` — выгружается соответствующая отрасль.

Каждая книга содержит шесть листов в порядке исходной публикации:

1. `в рублях`;
2. `в т.ч. просроч. в рублях`;
3. `в инвалюте`;
4. `в т.ч. просроч. в инвалюте`;
5. `итого`;
6. `в т.ч. просроч. итого`.

На листах строки соответствуют географической раскладке ЦБ, столбцы — отчетным
датам. Заголовок формируется из имени выбранной отрасли. Для `total` используется
формулировка «всего по видам экономической деятельности и отдельным направлениям
использования средств», чтобы не выдавать опубликованную строку за расчетную сумму
ОКВЭД.

Пример двух книг из одного полного потока:

```python
stream = build_cbr_0105a_debt_corp_stream(...)

export_cbr_0105a_debt_corp_industry_workbook(
    stream,
    Cbr0105ADebtCorpIndustryWorkbookRequest(
        out_path="apk.xlsx",
        industry_code="apk",
        overwrite=True,
    ),
)

export_cbr_0105a_debt_corp_industry_workbook(
    stream,
    Cbr0105ADebtCorpIndustryWorkbookRequest(
        out_path="total.xlsx",
        industry_code="total",
        overwrite=True,
    ),
)
```

## Pivot set

Пример структуры:

```python
Cbr0105ADebtCorpPivotRequest(
    row_dimension="region_code",
    column_dimension="report_date",
    value_columns=("value",),
    sheet_dimensions=("measure", "currency_scope"),
)
```

Если поток заранее отфильтрован до одной отрасли, результат содержит шесть таблиц:

1. задолженность — рубли;
2. задолженность — инвалюта;
3. задолженность — итого;
4. просрочка — рубли;
5. просрочка — инвалюта;
6. просрочка — итого.

Можно выбрать несколько числовых полей. Тогда таблица получает двухуровневые
столбцы: значение `column_dimension` и имя числового поля.

## Excel

Операция сохранения получает только готовый `Cbr0105ADebtCorpPivotSetResult`.
Она не скачивает источники, не фильтрует поток и не перестраивает pivot.
Минимальное оформление включает заголовки, закрепление областей, автофильтр,
ширины столбцов и числовой формат.
