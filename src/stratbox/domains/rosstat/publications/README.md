# Rosstat publisher materials

This package belongs to the single root `rosstat` operation owner. It identifies
**series → publisher issue → logical asset → original byte version**, independently
of statistical periods and downstream table meanings.

Registered operations live in `../operations/`: discovery, explicit selection,
review of exact-index coverage, update comparison, acquisition, acquisition to
storage, regional archive inspection and exact member extraction. The four root
registries supply the public source catalog.

The family rules recognize numeric issue labels, Russian named months and
January-to-month release ranges. URL relocation and source revision remain
separate concepts. An unverified index supports explicit candidate selection;
complete inventories, automatic latest selection and absence-based notifications
require reviewed scope evidence for the exact publisher-acquired index.

Regional ZIP/RAR members retain their container digest, exact path and own byte
identity. Full workbook and document decoding belongs to `tables/`; original
retention and artifact transfer use neutral core storage operations. Destination,
scheduling, access policy, version commits and delivery remain caller-owned.

and [complete processing route](../../../../../docs/current-how/rosstat-data-route.md).
