# CBR source tables and flakes

Each family owns its source layout, table edition and physical extraction.
Statistical workbook profiles retain every admitted cell before interpretation;
reporting forms retain archive members and supported DBF records. Specialized
industry, project-finance and office layouts preserve their own source evidence.

These values can be retained as complete snapshots. Semantic mappings, financial
models and product styles remain downstream of this owner.
