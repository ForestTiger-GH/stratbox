# Corporate lending source tables

This boundary owns source profiles, source-local contracts and interpretation.
The `industry` source dimensions and geography layout are shared by debt and
issuance. The independent observation route consumes complete workbook cells
and retains all selected periods, precise values, missing-cell status and source
coordinates before shared identities or SORS intervals are assigned.

Continue to [integration](../../integration/corporate_lending/README.md) for
aligned histories and model inputs, or to the
[operation API](../../operations/corporate_lending/README.md) for runner admission.
