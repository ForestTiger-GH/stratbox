# Reporting-form semantic alignment

Align reviewed source projections to versioned observations with distinct bank
and banking-group namespaces, explicit monetary scale, value status, reporting
date, period and source-record evidence. Income-statement periods and canonical
subject mappings require explicit input.

[Source tables](../../tables/reporting_forms) own physical layouts.
[Model admission](../../analytics/reporting_forms) validates aligned observations
before financial calculation. [Operations](../../operations/reporting_forms)
expose alignment and portable observation snapshots.
