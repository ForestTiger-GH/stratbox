# CBR semantic integration

Family operations align qualified source values, subjects, geography, periods,
units and metric definitions under explicit mappings. Integrated histories keep
source editions, input identities, missing-value statuses and qualifications.
Storage adapters can reopen the same complete logical value for downstream use.

Method-specific model preparation belongs to analytics when it depends on that
method's assumptions and constraint contracts.
