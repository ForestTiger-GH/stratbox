# Office-count semantic alignment

Apply explicit subject, territory and metric mappings to qualified source
observations. Preserve source identities and mapping editions. Unresolved
geography remains qualified unless the request requires complete resolution.
Count units and scales cannot change through an identity mapping.

[Source tables](../../tables/service_network) own publication qualifications.
[Calculations](../../analytics/service_network) compare aligned counts.
[Operations](../../operations/service_network) expose these boundaries and
portable semantic snapshots.
