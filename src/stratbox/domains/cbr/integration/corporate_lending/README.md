# Corporate lending integration

This boundary aligns already extracted industry values across selected releases
under explicit revision and geography rules. It retains source-local flakes
alongside the integrated history.

[Source interpretation](../../tables/corporate_lending/README.md) remains
independent. [Analytical models](../../analytics/corporate_lending/README.md)
consume qualified values; method-specific SORS input preparation belongs to
that analytical owner. Runner admission and explicit compositions belong to
the [operation API](../../operations/corporate_lending/README.md).
