# Office-count presentation products

Prepare selected office observations as a typed view with period, unit, status
and evidence columns. Render an admitted prepared view to CSV or XLSX after any
logical dataset storage boundary. Source parsing and calculation remain separate
from rendering and destination selection.

[Calculation](../../analytics/service_network) owns count differences.
[Operations](../../operations/service_network) expose view preparation and file
rendering through the caller's selected infrastructure.
