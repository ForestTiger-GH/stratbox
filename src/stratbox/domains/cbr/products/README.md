# Bank of Russia presentation products

Product specifications select scientific content and presentation methods for
accepted observations or model results. [Corporate-lending products](corporate_lending/)
and [reporting-form products](reporting_forms/) retain their own content contracts.

The [domain catalog](../domain.py) binds those methods to standard view and
render actions. Products return prepared views or encoded representations.
Common storage and publication commands own external delivery.

See [the product route](../../../../../docs/current-how/cbr-capability-migration.md).
