# SORS restoration

Restore regional economic activity observations using the published corporate,
SME and SME-IE constraints. Inspect bounds, feasibility and the original
evidence tiers through the typed result. Build pivots and workbooks as
separate representations.

Source bundles, strict results and crosswalk results can each be retained as a
complete `DatasetSnapshot` and reconstructed in a new process. Results carry
explicit typed source and configuration dependencies; computational models are
rebuilt from data rather than serialized solver objects. The source dependency
manifest declares ten required publications and one optional history input.
