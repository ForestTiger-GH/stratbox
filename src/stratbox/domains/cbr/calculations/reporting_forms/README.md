# Reporting-form calculations

This package owns reviewed form mappings, formula evaluation and their scientific
input requirements. Source extraction and financial-model acceptance have
separate scopes; a readable source field alone does not supply a missing model.

Calculation purposes are bound by the [domain catalog](../../domain.py).
[Reporting-form layouts](../../methods/tables/reporting_forms/) own the source
geometry, and [products](../../products/reporting_forms/) own presentation.

See [form semantics and missing periods](../../../../../../docs/current-how/cbr-forms-semantic-model-and-missing-periods.md).
