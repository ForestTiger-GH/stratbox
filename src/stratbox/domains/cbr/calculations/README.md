# Bank of Russia numerical purposes

Calculations consume accepted observations or complete model inputs.
[Reporting-form models](reporting_forms/) apply reviewed form-specific meanings;
[SORS](sors/) reconstructs a coupled system under its declared constraints.
Industry calculations have their own source and component requirements.

The [domain catalog](../domain.py) binds these purposes to standard calculation
commands. Common numerical mechanisms and execution remain in core.
See [calculation and source boundaries](../../../../../docs/current-how/cbr-capability-migration.md).
