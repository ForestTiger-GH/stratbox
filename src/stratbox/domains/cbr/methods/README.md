# Bank of Russia source methods

[Publication methods](publications/) interpret publisher links and issue evidence.
[Table methods](tables/) supply source geometry and scientific interpretation.
[Alignment methods](alignment/) apply explicit identity and geography mappings.

The [action methods](actions/) connect those scientific mechanisms to standard
named input/output contracts. Their specifications are selected by the
[domain catalog](../domain.py); physical decoding and execution remain common.

See [the source processing route](../../../../../docs/current-how/cbr-data-pipeline.md).
