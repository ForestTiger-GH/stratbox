# Bank of Russia publication evidence

This package owns source-specific recognition of publisher links, dates and
publication candidates. [Corporate-lending rules](corporate_lending/) retain the
relationships between published workbooks and their issue evidence.

Standard request, scan, selection and attribution methods are bound by the
[domain catalog](../../domain.py) through [action adapters](../actions/).
HTTP transfer belongs to core. Table meaning is established by
[table interpretation](../tables/).
