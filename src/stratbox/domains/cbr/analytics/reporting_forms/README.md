# Reporting-form financial models

Admit reviewed aligned observations as immutable model inputs, preserving
subject identities, units, periods, account-plan axes and complete source
channels. The calculator evaluates six explicit model editions. Subject
selection defaults to all admitted registrations; the historical selection is
an explicit profile.

[Alignment](../../integration/reporting_forms) owns semantic source observations.
[Operations](../../operations/reporting_forms) expose independent preparation and
calculation plus a source-projection composition. [Products](../../products/reporting_forms)
prepare views and render their workbooks.
