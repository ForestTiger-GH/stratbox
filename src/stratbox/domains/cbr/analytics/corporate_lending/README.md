# Corporate lending analytics

The shared industry model owns APK component requirements and formulas. The
SORS model owns qualified input preparation, quantity and constraint construction, strict restoration,
rounding inference, optimization and crosswalk calculations. Their input and
result contracts retain the qualified evidence needed for separate continuation.

[Shared industry integration](../../integration/corporate_lending/README.md)
aligns source histories. The SORS `inputs` boundary prepares its complete
model bundle from independent observations using declared model-specific rules. [Products](../../products/corporate_lending/README.md) prepare and render
selected views. Source-file acquisition and interpretation are outside this
analytical boundary.
