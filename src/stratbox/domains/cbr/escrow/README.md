# Escrow publications

This domain owns Bank of Russia project-financing publication recognition,
publication-local XLSX extraction, integration of selected flakes, and prepared
workbook views. Storage and remote publication use caller-selected core adapters.

A parsed file retains source identity, row order, every selected indicator cell,
unknown columns, raw decoded tokens and parse status. Independent operations
encode and restore flakes, integrated datasets and prepared views as complete
`DatasetSnapshot` values. Integration accepts restored flakes; rendering accepts
restored prepared views and performs no source acquisition or integration.

Historical HTML issues remain discoverable and can be acquired as originals.
Their table interpretation has an explicit unsupported layout status. Source
coverage remains distinct from successful processing of a supplied selection.

See [the escrow route](../../../../docs/current-how/cbr-escrow.md) for independent
operations, storage examples, duplicate policy and interpretation limits.
