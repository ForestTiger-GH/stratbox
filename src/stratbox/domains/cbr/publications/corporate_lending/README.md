# Corporate lending publications

This boundary owns discovered publication asset contracts, official-index link
discovery, canonical filename dates and the relationship between issuance
release dates and observation months. Workbook sheet layouts and numeric
interpretation belong to [source tables](../../tables/corporate_lending/README.md).

Use the [operation API](../../operations/corporate_lending/README.md) for
acquisition and bounded execution, or the shared publication catalog to discover
logical series and their source profiles.
