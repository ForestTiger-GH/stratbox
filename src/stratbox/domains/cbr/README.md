# Bank of Russia statistics

The [domain catalog](domain.py) binds continuing series, calculations and products
to standard actions. [Common facts](common/) define reusable publisher access and
semantics; [series](series/) declare each source's command specifications.

[Methods](methods/) recognize publications and interpret physical source evidence.
[Calculations](calculations/) own numerical purposes such as reporting-form models
and SORS. [Products](products/) prepare source-aware views and representations.

Use the [SDK](../../sdk/) to execute a selected standard route.
See [source processing and scientific scope](../../../../docs/current-how/cbr-data-pipeline.md).
