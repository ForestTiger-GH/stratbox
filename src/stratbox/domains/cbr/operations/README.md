# CBR callable operations and qualified compositions

Each functional segment defines typed requests, operation semantics and thin
handlers. The root CBR registration aggregates these segments. Source and family
cards resolve exact operation versions, table editions, semantic profiles,
handoffs and coverage qualifications from that single executable catalog.

Independent stages can resume from retained logical values. Convenience routes
declare their multi-stage composition explicitly. Neutral storage and material
operations remain shared core capabilities.
