# FNS statistical data

`domain.py` is the static entry point for the SME register and Form 1-YUR.
`series/` declares command methods and their narrow immutable settings;
`common/` owns shared access, publication and historical semantic facts;
`methods/` interprets already supplied evidence. Calculations and products
reference standard numerical and rendering commands.

The SME interpreter preserves all nine reviewed counters, published geographic
levels and date-attribution checks. Missing counters remain missing. The 1-YUR
interpreter retains reviewed historical Part I fields, original categories,
territories, source coordinates and incomplete-coverage findings. Event counts
with unresolved accumulation periods cannot be treated as stock changes.

Transport, physical decoding, bounded execution, retention and journal-based
notifications belong to the common core. Domain methods perform no hidden
acquisition, storage or delivery. Public callers use the standard capability
catalog and select an exact series through `DOMAIN`.
