# FNS statistical publications

The [domain catalog](domain.py) declares the SME register and Form 1-YUR.
[Common facts](common/) own publication access and reviewed semantics;
[series specifications](series/) bind standard commands to [methods](methods/).

Source methods preserve published geography, date attribution, raw categories
and incomplete-coverage findings. Calculations and [products](products/) consume
the resulting observations. HTTP, physical decoding, execution and retention
use common core actions.

See [source interpretation and coverage](../../../../docs/current-how/fns-data-pipeline.md)
and [standard command bindings](../../../../docs/current-how/fns-capability-migration.md).
