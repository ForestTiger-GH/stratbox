# Standard command contracts

The command catalog defines reusable actions, their typed ports, acceptance,
provider requirements, resource classes and effect declarations.

Use these definitions to compose operations, scenarios and cascades. A domain
specializes an action through its method, settings and applicability; it does
not replace the standard action's meaning or runtime authority.

Technical handlers belong to [core commands](../../core/commands/).
[Preparation](../preparation/) binds the selected specification before execution.
See [the typed processing stages](../../../../docs/current-how/standard-data-stages.md).
