# Portable analytical values

This package owns material and physical-evidence carriers, source and integrated
datasets, time series, views, encoded products and their qualifications.
Typed source coordinates and uses preserve the relationship between observations,
publication context and exact evidence.

Values cross standard command ports. Their canonical representation supports
identity and retained replay; execution, provider selection and external storage
belong to core. Publisher-specific parsers and scientific settings belong to domains.

See [semantic contracts](../../../../docs/current-how/shared-semantic-contracts.md)
and [independent processing stages](../../../../docs/current-how/standard-data-stages.md).
