# Shared data and evidence

Shared types describe bytes, source attribution, physical evidence, observations, time series, coverage and calendar meaning. They perform no execution or publisher selection. Stable identifiers address concepts; fingerprints identify actual content.

See [semantic contracts](../../../docs/current-how/shared-semantic-contracts.md), [references](reference/README.md), and [ownership](../../../docs/architecture/shared-ownership.md).
