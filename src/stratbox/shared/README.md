# Shared values and reference meaning

Shared types describe materials, source attribution, physical evidence,
observations, time series, coverage and calendar meaning. They carry data and
qualified identity across execution and domain boundaries.

Use [data contracts](data/) for portable values and source-use evidence,
[reference data](reference/) for reviewed identifier and naming inputs, and
[time helpers](time/) for calendar semantics. Fingerprints identify actual
content; conceptual identifiers address its role.

See [semantic contracts](../../../docs/current-how/shared-semantic-contracts.md)
and [shared ownership](../../../docs/architecture/shared-ownership.md).
