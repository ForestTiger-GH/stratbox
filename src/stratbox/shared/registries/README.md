# registries

Этот раздел содержит **реестры и справочники**, которые используются в разных скриптах и ноутбуках (например, обработка форм ЦБ, отчёты, графики, фильтры банков, справочники отраслей).

## Куда идти дальше
👉 **Реальные данные (файлы реестров) лежат не здесь, а в:**
- [`_resources/`](./_resources/)

В этой папке (`registries/`) лежит только **код-обёртки**, который читает и приводит реестры к удобному формату.

---

## Что здесь есть

### 1) Реестр банков ЦБ РФ: `cbr_banks`
- Код: [`cbr_banks.py`](./cbr_banks.py)
- Что делает:
  - читает **XLSX-реестр ЦБ** из `_resources/cbr_banks/`
  - добавляет колонку нормализованного названия банка (CAPS)
  - применяет **финальную канонизацию** через `cbr_replacements` (например: `СБЕРБАНК → СБЕР`, `Т-БАНК → ТБАНК`, `РОССЕЛЬХОЗБАНК → РСХБ`)
  - добавляет флаги и доп. поля для удобства: `is_canonical`, `replacements_json`, `is_legacy`, `lic_status` и др.

Как использовать в коде:
```python
from stratbox.shared.registries import cbr_banks
df = cbr_banks.read()
```

### 2) Реестр ОКВЭД2 (Росстат): `rosstat_okved2`
- Код: [`rosstat_okved2.py`](./rosstat_okved2.py)
- Что делает:
  - читает три CSV-файла выгрузки Росстата из `_resources/rosstat_okved2/`
  - возвращает “плоскую” таблицу `section / code / name` для дальнейших расчётов.

Как использовать:
```python
from stratbox.shared.registries import rosstat_okved2
df = rosstat_okved2.read()
```

## Обновление реестров
Реестры обновляются **вручную** — это нормальная и ожидаемая логика (без сложных автозагрузок, чтобы коллегам было проще).

👉 Все действия по обновлению делаются в папке:
- [`registries/_resources/`](./_resources/)
