# Crosswalk relation system

## Текущий статус

Crosswalk старой и новой классификаций остаётся отдельным условным контуром. Его пакет ресурсов содержит legacy atoms, membership и допустимые atom→class edges.

Проверка реальных таблиц на 01.06.2026 показала, что текущие жёсткие сценарии `core` и `broad` несовместимы с частью опубликованных денежных агрегатов. Поэтому они не внедряются в официальный target graph и не могут помогать STRICT Fact Ledger.

## Правило подключения

Будущий crosswalk profile может участвовать в поклеточном движке только после:

1. компиляции всех отношений сценария;
2. deterministic closure без конфликтов;
3. глобальной feasibility;
4. явного evidence profile/version;
5. запрета любых мягких benchmark-потоков в доказательном слое.

После этого crosswalk-relations могут стать дополнительными horizons локальной РКВС. До выполнения gate они остаются диагностикой.

## Отдельный API

`run_sors_crosswalk()` сохранён для исследования mapping-сценариев и их конфликтов. Его результат не смешивается с STRICT автоматически.
