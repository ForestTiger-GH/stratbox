# Контракты источников

Каждая исходная ячейка получает стабильный `observation_id`, SHA файла, координаты листа и канонические поля даты, географии, классификатора, метрики, валюты, значения и публикационного интервала.

Обязательные проверки:

- одна отчётная дата;
- ожидаемые листы и категории;
- отсутствие дубликатов;
- неотрицательность;
- `RUB + FX ≈ total` с учётом округления;
- `overdue <= debt`;
- региональные, окружные и российские балансы;
- совпадение итогов между источниками;
- корректная атомизация Архангельской и Тюменской областей.

`01_05_D` имеет роль `VALIDATION_AND_HISTORY`: наблюдения сохраняются в source evidence и связываются с теми же логическими количествами, но не создают дублирующие LP-строки.
