# Core — компонентное целевое представление

**Owner реализации:** `ForestTiger-GH/stratbox`. **Status:** базовый доменный/headless контур `BOUNDARY_ACCEPTED`; дальнейшая нормализация `CANDIDATE`.

**Роль:** библиотечно предоставлять получение и преобразование внешних макроэкономических и банковских источников, канонизацию, проверку, предметные вычисления, структурированные результаты и экспорт. Внутри уже существуют source collecting, regulatory reporting, отраслевые ряды, escrow и специализированные реконструкции.

**Граница:** core не владеет GUI, desktop lifetime, связным многопользовательским application session или внешней платформой установки. Дополнительные окружения должны подключаться через общие публичные инфраструктурные контракты, а не внедрять внешнюю физическую реализацию в доменные алгоритмы.

**Candidate properties:** стабильная предметная операция со структурированным Request/Result, описание side effects, qualification/provenance исходных данных, информативные missing/error states, контроль схем источников и версий справочников. Конкретные operation IDs, schema fields, поддерживаемые series и domain acceptance thresholds требуют полного Product admission.

**Критерий границы:** core можно вызывать непосредственно как Python dependency без импорта desktop toolkit; данные, архивы и вычисления остаются независимыми от пользовательской панели. Этот текст не обещает универсальную обработку всех форм и источников.
