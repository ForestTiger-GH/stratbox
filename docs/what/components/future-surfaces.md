# Будущие клиентские поверхности — профили, а не обещания выпуска

**Status:** CONDITIONAL / product scope and delivery unapproved.

**Android:** предусмотрено будущее переиспользование предметной application/surface семантики (operation specs, projections, statuses, validation) из Windows-наработок. Размер собственно Android-приложения, full-featured vs companion, offline behavior, background permissions, authentication и toolkit остаются открытыми.

**Web/shared-node:** потенциальный самостоятельный UI/profile, допускаемый только при наличии проверенных authority, сессий, разделения участников, безопасности сети и состояния. Текущее desktop приложение не доказывает эти гарантии.

**Допустимые ИИ-агенты и другие клиенты:** рассматриваются абстрактно как permissioned consumers. Наличие сценария автоматизации не создаёт самостоятельных полномочий, не гарантирует публичный API и не повышает права доступа.

**Общее свойство будущего варианта:** каждый опубликованный профиль перечисляет конкретные поддержанные задачи, ограничения, требуемое окружение и происхождение состояния. Отсутствующий профиль отображается как будущий/неподдерживаемый, а не скрыто эмулируется.
