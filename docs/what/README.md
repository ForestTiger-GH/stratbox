# Target WHAT — Strategy Box

**Статус: целевая модель ещё не собрана и не принята.**

Здесь будет единая целевая модель продукта: назначение, пользователи, сущности, отношения, поведение, качества, ограничения, допустимые варианты, инварианты и проверяемые обязательства.

Общая модель и представления аналитического ядра, прикладной среды исполнения, Windows-клиента и будущих платформ образуют один согласованный Target WHAT. Физический репозиторий реализации не становится самостоятельным источником конкурирующего продуктового смысла.

Каждое существенное требование должно иметь основание в поручении/решении компетентного владельца, статус и область применимости. Высокая уверенность исследования сама по себе не означает принятого обязательства. Читатель WHAT должен понимать обещания продукта без чтения Science или HOW.
