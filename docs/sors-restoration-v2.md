# SORS Restoration V2

См. доменную документацию:

`src/stratbox/macrobanks/cbr_sors_restoration/README.md`

V2 является breaking redesign текущего SORS-прототипа. Основные изменения:

1. четыре книги и все шесть денежных листов участвуют в модели;
2. все 96 опубликованных географических узлов ограничивают 85 атомарных территорий;
3. используются 88 реальных классов ОКВЭД2, публикационное `Прочее` выражается группой классов;
4. strict-публикации и условный bridge разведены по разным evidence layers;
5. сертифицируются шесть пользовательских линейных метрик, а не только латентные компоненты;
6. SciPy удалён из зависимостей SORS, production backend — `highspy`;
7. результат формируется как доказательный GRID с исходными и восстановленными строками.
