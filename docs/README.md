## Границы утверждений

**Strategy Box — один продукт, несколько владельцев реализации.** `stratbox` владеет аналитическим ядром, `stratbox-windows` — собственной действующей Windows-реализацией. Внешняя управляемая платформа владеет своей установкой, запуском и подтверждёнными versioned interface. Наличие концепции будущих server/mobile/API возможностей не доказывает, что они уже реализованы.

Публикуемый Current HOW реконструирован по exact code snapshots, **без запуска GUI/pytest или подтверждённого реального deployment**. Научные статьи имеют прямые code/evidence ссылки, но полный перенос исходных исследований и `docs_old/` ещё не доказан. В целевых материалах `CANDIDATE` и `CONDITIONAL` не означают принятые продуктовые обещания; детальная authority, retention и recovery ещё уточняются.

Все решения о том, что пользователь получит в будущем, принадлежат соответствующему Product/Decision owner. Никакая исследовательская рекомендация не становится обязательством через включение в документацию.

## Навигация и история

Это основной вход для опубликованных **ограниченных** знаний. Исторические core-документы находятся в [docs_old/](../docs_old/README.md); они сохранены для проверки происхождения, но не являются конкурирующим владельцем современного WHAT/HOW. Поддерживаемые научные статьи должны быть достаточными без постоянного обращения к истории только в **уже подтверждённых узких темах**.

Авторитетный source census, material-unit accounting, решения и проверки полноты находятся в рабочем контуре [consolidation/](../_mw/epochs-001-strategy-box-development/consolidation/README.md), а не во втором публичном Science-каталоге. Неопределённое состояние всего корпуса отмечено там явно.

**Доступ и безопасность:** опубликованные разделы содержат только общие публично допустимые границы и проверяемые реализации. Детали закрытых расширений, внутренние адреса и реализации не относятся к этому корпусу.
