# Target HOW — реализация и эксплуатация

**Статус: целевые механизмы ещё не собраны и не приняты.**

Здесь будет описано, как реализуются требования Target WHAT, как система применяется и как действует при запуске, обновлении, сбое, восстановлении и завершении эксплуатации.

Для существенных выборов указывать конкретное поведение, границы, сбои, проверку и свободу реализации: зафиксировано, ограниченно открыто либо блокируется неразрешённым решением. Механизмы должны быть достаточно полными для реализации и проверки без возврата к истории исследований. Интеграции с AppDock должны различать подтверждённые интерфейсы и будущие Data/Control возможности.
