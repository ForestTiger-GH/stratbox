# Применение Strategy Box — HOW-A

**Status:** ограниченный продуктовый сценарий на принятой границе core и условных механизмах Target HOW.

## Прямое применение аналитиком

1. Определить источники, период, регион/отрасль/банковскую форму и требуемый артефакт; проверить, что функция заявлена установленным capability catalogue.
2. Проверить версию источника и метрику: опубликованная округлённая цифра, производная оценка и неизвестное значение относятся к разным доказательным классам.
3. Выбрать доступную операцию, ввести профильные параметры, определить конечный output scope и подтвердить возможные внешние эффекты, если они предусмотрены политикой данной поставки.
4. Запустить операцию через разрешённую поверхность. Пользовательский Case/Run идентификатор предназначен для повторного просмотра; повтор одного намерения и запуск **нового** намерения должны быть различимы.
5. Дождаться именно подтверждённого результата операции и отдельно посмотреть публикационный статус каждого файла. Частичный результат не равен полному.
6. При ошибке получить безопасный код и диагностический идентификатор; технический traceback доступен только через разрешённую диагностику.
7. При повторном использовании данных учитывать исходную периодизацию, единицы измерения, статус реконструкции, версии справочников и ограничения сравнения.

Пункты о единой системе разрешений, глобальных Run ID и управляемой публикации артефактов здесь **предложены для последующей принятой поставки**; текущая UI реализация отличается.

## Внешний разрешённый потребитель

Разрешённый ИИ-агент или иной автоматический клиент вправе видеть **только** открытый для него перечень операций и валидные схемы входа. Для рисковых эффектов нужны отдельная проверка права и policy-bound approval. Передача полномочия на чтение не создаёт права изменения данных; статус успешного расчёта не означает, что агент вправе разослать или удалить итог.

**Вызовы, которые должны завершиться контролируемым отказом после принятия целевого контракта:** неизвестная operation identity, неподдерживаемая версия input schema, недоступная среда, invalid parameters, недостаточные права, истёкшая approval, конфликтующее повторное обращение или превышение ресурсного бюджета. До принятия публичного machine API ни URL, ни метод, ни transport schema не устанавливаются.

## Варианты

**Local analyst:** может работать внутри одного пользовательского сеанса; локальность не доказывает наличие фоновой работы после закрытия окна. **Managed shared host:** требует самостоятельного identity, read isolation, persistent job authority и confirmed external hosting contract; пока не является supported release. **Android companion:** предполагает упрощённые действия только после утверждения, не обещает запуск тяжёлых вычислений на телефоне.

## Ошибки интерпретации

- Закрытие окна не подтверждает отмену задачи; действующий режим определяет фактический lifecycle.
- Отсутствие уведомления не подтверждает успешного окончания или отсутствия ошибки.
- Файл с тем же именем может содержать новую версию исходных данных.
- Официально опубликованное округление нельзя считать точной неокруглённой суммой.
- При неизвестном исходе опасной операции автоматический новый запуск без проверки результата несёт риск повторного эффекта.

**Reopen:** принятый способ ввода/отмены/повтора, новые банковские домены, изменение artifact policy, новые клиенты и machine interface.
