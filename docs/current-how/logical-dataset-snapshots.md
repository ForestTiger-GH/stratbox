# Portable semantic data

`command.value.encode` turns an admitted semantic value into an explicit representation; `command.value.decode` restores only the fixed admitted type vocabulary. A domain scientific carrier uses a dedicated declared codec when the generic vocabulary cannot represent it. An encoded value retains exact decimals, source context, assessment and input evidence.

`operation.dataset.retain` composes encoding with an explicit immutable storage effect. Reading or transferring bytes is distinct from decoding, semantic validation, analytical calculation and publication. Replaying a dataset requires its declared source context and never silently relabels it as another target.

Actual content fingerprints replace component counters. A fingerprint detects a changed value; a retained immutable reference preserves the bytes required for replay.
