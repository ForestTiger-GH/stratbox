# Static domain catalogs and qualified scientific routes

Each publisher has one immutable `DOMAIN`, containing its common facts,
continuing table series, calculation models and products. The domain supplies
methods and narrow settings for standard commands. The standard graphs and
technical execution remain source-independent.

Coverage is scoped to actual reviewed methods and publisher material. The
presence of a static source record or a generic decoder does not supply missing
scientific interpretation.

## Contents

1. Catalog records — direct references and exact action methods.
2. Publisher scope — supported responsibilities and remaining evidence limits.
3. Independent entry — reuse retained material, observations and numerical data.

## 1. Direct records

The fixed domain manifest addresses `domains.<publisher>.domain:DOMAIN`.
`DOMAIN.series[id].commands[command_id]` selects a method, settings and
applicability. Shared addresses, dictionaries and rules have one authoring owner.
There is no profile registry, package-scanning registration or command generator.

A series describes a continuing logical table or coherent set of its parts.
A publication issue and asset describe a particular occurrence. Numerical
histories are selected observations within those tables. They are not additional
publisher source declarations.

## 2. Publisher responsibilities

| Publisher | Source responsibility | Scientific qualification |
| --- | --- | --- |
| CBR | Statistical tables, reporting forms, offices, project finance and corporate-lending calculations. | Explicit layout/field contracts; financial formulas and inference have their own acceptance. |
| FNS | SME counts and legal-entity registration statistics. | Read-only JSON and historical workbook layouts; stocks and registration events stay distinct. |
| Minfin | Federal/consolidated/regional budgets and National Wealth Fund publications. | Reporting date, accumulated flow, stock, currency and mixed-row meaning are explicit. |
| Frank RG | Fourteen delivered-file series and their numerical projections. | File recognition is not proof of a reviewed economic layout. Publisher mappings require actual supplied material. |
| Rosstat | Four publication families and reviewed logical table sets. | KEP2 eleven-indicator scope, municipal population and regional industrial tables have explicit limits; national PDF text alone does not establish table interpretation. |

A financial reporting form's extracted fields do not automatically establish a
reviewed financial model. Missing reviewed formulas for forms 134/803 remain
explicit analytical limitations. Document interpretation requires reviewed
geometry/field rules; caller-supplied bytes do not manufacture those rules.

Readiness has independent dimensions: applicability, implementation,
composability, synthetic/publisher verification and current environment access.
An unavailable live site and verified retained publisher evidence can coexist.

## 3. Independent entry and results

Supplied originals can enter extraction without HTTP. Supplied physical evidence
can bypass decoding. Retained datasets can feed calculations without publisher
access. A database-selected numerical history can be calculated without a
publisher-Series declaration. Rendering a retained accepted view has no source
acquisition dependency.

Source changes, rule changes, missing downstream products and new destinations
are separate work decisions. A source check returns its assessment and evidence;
only suitable material/evidence ports feed later parsing. Journals preserve the
qualified results and effects at command, operation, scenario and cascade scope.
