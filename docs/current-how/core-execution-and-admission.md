# Admission and resource scheduling

`StrategyBox.prepare()` resolves a capability and optional domain target into a prepared plan. The selected entrance determines its actual closure: supplied physical evidence prunes decoding and acquisition. The service checks the providers, resources and supplied input contracts of that closure before work begins.

`ExecutionSettings` bounds workers, active runs, shared resource classes, retained bytes and journal capacity. Concurrent runs share these limits and compatible physical work. Bounded maps expose each selected unit outcome; bounded iteration requires convergence and reports exhaustion explicitly.

Use `submit()` for concurrent work, the returned handle for status and cancellation, and `result()` for accepted named outputs. Close results when consumed and close the service when its owner finishes. See [SDK execution](capability-session.md).
