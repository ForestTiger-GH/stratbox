# Discover processing capabilities

`StrategyBox.discover(kind=..., query=..., offset=..., limit=...)` returns bounded metadata pages for commands, operations, scenarios and cascades. `describe(id)` exposes explicit semantic ports, requirements and summaries. `sources.list()` and `sources.describe(series_id)` expose continuing domain records.

Discovery imports metadata without opening transports or requiring numerical and workbook engines. Preparation resolves only the requested source and entrance. A metadata entry establishes the declared contract; actual provider and scientific readiness are checked separately.
