# Reporting forms and declared financial models

Reporting-form routes separate archive selection, DBF/workbook decoding, source field interpretation, semantic validation, explicit model calculation and product rendering. Dated account-plan and chapter rules remain domain knowledge. Absent optional fields, blank cells, zeros, wrong numeric dialects and incomplete source geometry keep distinct outcomes.

Financial calculation requires the declared unit, scale, period, account-plan namespace, source fields and model applicability. The six packaged model CSVs are verified individually in source and installed distributions. Scientific provenance identifies the actual source bank, source period and contributing fields.

Forms 134 and 803 retain source-field extraction. Complete reviewed financial equation models for those forms require authoritative model evidence; the library does not invent them. Missing model evidence yields an explicit unsupported calculation.
