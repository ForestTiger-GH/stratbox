# Escrow table interpretation

Escrow sources declare publication discovery, worksheet geometry, source periods, metric identities, units and scale. Extraction preserves original rows and source totals; interpretation produces typed observations with exact cell evidence. Geographic name annotations preserve source row objects and statistical perimeters.

A fetched file, a recognized workbook, a semantic dataset and a rendered product are independently meaningful outputs. Domain methods supply source settings to standard commands; they perform no implicit notification or external save.

Use `scenario.series.refresh` with the discovered escrow series target. Supplied physical evidence prunes acquisition and decoding. Validation rejects contradictory source identities, dates, duplicate coordinates and malformed geometry before calculations.
