# CBR command catalog

`stratbox.domains.cbr.domain.DOMAIN` is the direct domain entry. Its immutable series records bind standard command IDs to source methods and reusable settings. Scientific calculations and products have separate records. There are no domain operation builders or per-table profile registries.

Use the ordinary SDK discovery, preparation and invocation API described in [CBR routes](cbr-data-pipeline.md). Exact source issue, source use, native cells, value status and references remain part of scientific evidence.
