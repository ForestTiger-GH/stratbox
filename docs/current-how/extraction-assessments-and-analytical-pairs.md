# Scientific acceptance and analytical comparability

Physical recognition establishes a representation, not a reviewed economic interpretation. Source methods declare exact fields, coordinates, units, scales, period kinds and perimeters. Assessment preserves missing, withheld, ambiguous and partial data as explicit outcomes.

Calculations compare actual input grains and semantic bases. Ratios require compatible units and periods; stock changes require ordered comparable stocks; year-to-date flow conversion requires a coherent cumulative basis and adjacent periods. An unknown event accumulation cannot silently become a stock.

Complete axis marginals do not establish joint coordinate coverage. A filtered view preserves the limitations of its original source assessment. See [shared contracts](shared-semantic-contracts.md) and [source route limits](independent-domain-data-routes.md).
