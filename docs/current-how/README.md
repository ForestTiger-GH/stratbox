# Current HOW — фактическое состояние

**Статус: реконструкция по текущему коду ещё не завершена.**

Раздел будет описывать реально существующее устройство аналитического ядра и клиентских приложений. Для каждого существенного факта нужны точные версии, граница окружения и тип доказательства: исходный код, тест, выполненная проверка, наблюдаемое поведение либо остающийся UNKNOWN.

Current HOW не является проектом будущей системы. Исторические технические описания из `docs_old/` используются как источники для проверки, а не автоматически признаются текущими. До публикации подтверждённой модели текущим владельцем реализации остаётся непосредственный код соответствующего репозитория.
