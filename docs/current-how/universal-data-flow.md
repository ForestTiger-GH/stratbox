# Standard data flow

Source observation produces publication evidence and selected assets. Acquisition produces attributed material. Decoding produces physical evidence. Interpretation produces source observations. Validation and alignment produce qualified semantic inputs. Calculations produce derived observations; view preparation and rendering produce products. Storage and release publication establish explicit external effects.

Every stage has an independently callable command and a meaningful typed boundary. Supplied material, physical evidence, observations or a view can be an entrance when its contract is sufficient for the requested goal. See [standard stages](standard-data-stages.md).
