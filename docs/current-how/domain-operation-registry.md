# Static domain command catalogs

Every domain exports one `DOMAIN` record. Its continuing series, calculations and products map standard command IDs to explicit methods and reusable settings. `capabilities.catalog.domains.load_domains()` loads the explicit root manifest; `StrategyBox.sources` exposes source discovery.

Operations, scenarios and cascades stay source neutral in `capabilities`. Domains supply methods rather than operation builders, profile registries or runtime contributions. See [domain semantics](../architecture/domain-functional-semantics.md).
