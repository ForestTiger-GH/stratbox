# Supplied inputs and coherent releases

A supplied original uses the same decode, interpretation and validation commands as an acquired original. Supplied physical evidence prunes decoding. Supplied semantic data still passes source and semantic validation before downstream use. An explicit input is never replaced by an unrelated available transport.

`InvocationRequest` represents a callable, its input values, parameters and independent target. Source cascades accept a bounded tuple of such requests. Analysis-release cascades accept only members whose scientific work and required immutable writes succeeded.

Release assembly verifies concrete member references and publishes one manifest through an explicit compare-and-set transition. Computation success, member retention and release publication remain separate facts.
