# Критерии принятия

Значение может попасть в итоговый поток только если:

1. исходные книги успешно распознаны;
2. географическая база взаимоисключающая;
3. публикационное округление представлено интервалами;
4. соответствующий STRICT или CROSSWALK model feasibility подтверждён;
5. полный допустимый min/max является точкой либо одним публикационным bucket;
6. `value_identified=True`;
7. `is_final_accepted=True`;
8. имеется evidence layer, profile и proof ID.

При широком диапазоне:

```text
value = NULL
is_final_accepted = False
```

Benchmark или первая найденная Solver-таблица не могут заполнять `value`.

Crosswalk-факт является условно восстановленным фактом: его доказательство действительно при указанной версии mapping и сценарии. Он не маркируется `is_strict_fact=True`.
