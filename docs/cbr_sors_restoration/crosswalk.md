# Crosswalk relation system

## Ресурсы

Пакет `crosswalk/_resources` содержит:

- `legacy_atoms.csv` — непересекающиеся атомы старой классификации;
- `legacy_node_membership.csv` — состав опубликованных старых узлов;
- `atom_class_edges.csv` — допустимые атом→класс переходы по сценариям;
- `crosswalk_manifest.json` — версия и список сценариев.

## Почему это уравнения

Solver-column представляет конкретную денежную массу. Например:

```text
Белгородская область
× forestry
× class 02
× overdue_rub
```

Та же колонка входит в:

- старую строку лесного хозяйства;
- старую широкую строку сельского хозяйства и леса;
- класс 02 по России;
- раздел A по ЦФО;
- региональный итог Белгородской области;
- целевую ячейку Белгородская область × 02.

Поэтому соседние нули и остатки распространяются через всю систему.

## Core-сценарий

Core исправляет логические потери старой реализации:

- `forestry → 02`, а не `01|02`;
- `mining_other → 08`;
- `construction_other → 43`;
- `manufacturing_machinery_other → 26|27`;
- `manufacturing_transport_equipment_other → 30`;
- `transport_communications_other` исключает 51;
- издательский класс 58 сохраняется и не удаляется пересечением с родительским разделом C.

## Broad-сценарий

Broad сохраняет более широкие множества назначения для спорных остаточных атомов. Его назначение — проверить, остаётся ли значение идентифицированным при менее точной трактовке crosswalk.

## Принятие результата

`crosswalk_bounds_grid` содержит envelope и границы. `crosswalk_facts_grid` содержит только строки с `is_final_accepted=True`. При широком диапазоне поле `value` всегда пустое.


## Доказательный след

Каждая строка результата содержит версию mapping, сценарии и список crosswalk-relations, формирующих допустимый входящий поток класса. При нескольких сценариях `scenario_coverage_complete=True` выставляется только после того, как каждый настроенный сценарий либо подтверждён как совместимый, либо доказанно несовместим. Незавершённый сценарий блокирует принятие robust-value.
