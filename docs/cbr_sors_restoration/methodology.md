# Методология

Искомый объект — неотрицательный скрытый куб:

```text
атомарный регион × класс ОКВЭД2 × денежный компонент
```

Четыре непересекающихся компонента:

- performing RUB;
- overdue RUB;
- performing FX;
- overdue FX.

Из них выводятся шесть пользовательских метрик задолженности и просрочки.

Публикации в млн рублей задают полуоткрытые интервалы округления. Опубликованный ноль означает `[0; 0,5)`, а не математический ноль. Поэтому publication-zero исключает цель из дорогой min/max-сертификации, но не позволяет удалить скрытую переменную из модели.

Доказательный цикл:

1. распространение интервалов по равенствам `parent = sum(children)`;
2. global strict-feasibility;
3. min/max выбранных клеток;
4. запись новых bounds;
5. повторное deterministic closure;
6. остановка в fixed point или по заданному бюджету.

Conditional bridge минимизирует массу, ушедшую на непредпочтительные переходы традиционной классификации в ОКВЭД2. Его результат является условной оценкой и не повышается до strict-факта.
