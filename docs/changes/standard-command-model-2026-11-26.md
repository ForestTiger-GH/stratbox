# Standard commands, source specifications and direct execution

The implementation uses one source-independent capability layer and one execution service. Domain roots link immutable source-series records, common settings, scientific calculations and products. Repository release identity and exact content fingerprints replace component release counters.

## Semantic boundaries

Commands expose typed material, physical evidence, source observations, integrated/derived data, time series, views, products and effect receipts. Operations compose reusable transformations; scenarios own scientific and external-effect obligations; cascades coordinate independent scenarios. Supplied originals, physical evidence and retained observations use explicit entrances with the same acceptance rules.

Calculations operate on accepted semantic values. Independent series application uses bounded maps and per-unit outcomes. SORS retains a coupled constraint model with propagation, inheritance, reconciliation, global feasibility, optimization and certification as separate callable commands.

## Execution and evidence

The shared service schedules multiple runs under common resource and memory limits. Logical source attribution remains independent of compatible physical reuse. Journal records distinguish accepted outputs, composite completion and external effect confirmation. Notification intents follow journal selection and use deterministic identities, persisted cursors and explicit reconciliation.

Exact reference assets, financial model files and scientific state codecs are included in the package. Source-use evidence preserves publisher, issue, material, layout, semantic settings and input role. Coverage and partial findings survive later transformations.

## Scientific scope

Reviewed source methods and retained source excerpts provide the admitted scientific coverage. Complete financial equation models for CBR forms 134/803, actual cell mappings for the fourteen Frank RG series, three Minfin document mappings, additional Rosstat table mappings and canonical municipal crosswalks require reviewed source evidence. Generic decoding and metadata discovery do not establish those scientific interpretations.
