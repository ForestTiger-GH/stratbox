# Low-Level Design

**Статус: локальные проекты ещё не подготовлены.**

Детальные схемы создаются выборочно там, где сложность, безопасность, согласованность, сохранность данных, исполнение или пересечение границ требуют точного контракта.

Подходящие объекты: состояния Work/Run/Job, исполнение и побочные эффекты, транзакции и восстановление, источники и результаты, публикация артефактов, внешние адаптеры, разрешения и многопользовательский доступ.

Детальный проект опирается на определённые WHAT и HOW, задаёт интерфейсы, данные, условия отказа и тестовые примеры, но не дублирует исходный код и не объявляет несуществующие механизмы реализованными.
