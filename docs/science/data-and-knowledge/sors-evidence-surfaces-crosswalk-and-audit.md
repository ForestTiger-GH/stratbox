# SORS evidence surfaces, conditional classification crosswalks and auditable results

**Status:** scientific distinction with qualified historical software-design evidence, not a new Product Decision or certified execution of real regulatory inputs. The current source-based [reconstruction implementation account](../../current-how/sors-restoration-evidence-and-inference.md) supplies directly pinned code facts; the concepts below are self-contained even if the historical original documents disappear.

## 1. Source observations and validation precede inference

The intended model distinguishes an **original observation** from a constrained **latent quantity** and a reconstructed **published representative**. Each observation can carry an identity, exact input-byte digest, workbook coordinate, measurement date, region, classifier, metric, currency, raw value and publication interval. These fields let an analyst ask whether two cells refer to one economic statement or merely share the same textual label.

A historical source-contract checklist required single-date and expected-category checks, uniqueness, nonnegativity, `RUB + FX ≈ total` subject to rounding, `overdue ≤ debt`, reconciled region/district/country totals, inter-source agreement and explicit treatment of composite regions. An optional historical validation/history input could strengthen source trace without becoming a second independent equation for the same quantity. Such validation is a **bounded historical design contract**; real input files, execution logs and exact method version still determine which checks actually ran. [Scientific rounding meaning](publication-rounding-and-claim-strength.md) and [Current HOW](../../current-how/sors-restoration-evidence-and-inference.md) provide the relevant formal distinction.

**Negative case:** treating a duplicated observation as a new independent linear-programming constraint can create false confidence or mathematical inconsistency. A valid source file's hash and correctly parsed period do not themselves prove that two reporting definitions have matching geographic scope.

## 2. Deterministic evidence, selective optimization and controlled representation

The scientific decomposition is **fixed source constraints → deterministic fixed point and global feasibility → optional solver target search → weaker admissible representative selection**. A fixed point is the stage at which the source-preserving deterministic closure can no longer add a qualified bound or fact under its current rules. A prior historical interface described optimizer choices `none`, `targets`, `priority` and `all`. Their intended difference was which latent min/max target catalogue is explored, not whether the deterministic proof stage is allowed to disappear. Internal component quantities could be included in the search without changing the six published metrics which formed the main product-facing restoration scope.

An explicitly bounded priority search may favor tight finite ranges and user-facing metrics; it is cheaper than exhaustive all-target optimization but does **not** prove all unsearched categories are identified. The historical controlled-selection policy acted at a **later, weaker evidence tier** and must not rewrite official publication step, tolerance or interval endpoints. The current mathematical core's [tier separation](publication-rounding-and-claim-strength.md) is therefore more important than any one legacy mode name.

**Negative case:** a chosen feasible representative gets displayed as a regulator's exact number because the report omitted its tier and derivation. That is an epistemic promotion error even when the numerical choice satisfies every model constraint.

## 3. Classification crosswalks are qualified constraints, not automatic facts

Mapping between legacy and newer industrial classifications can involve legacy atoms, category membership and admissible atom-to-category edges. Such a map may be **useful diagnostic context** without automatically becoming a hard official relationship in the reconstruction model. A historical June 1, 2026 trial reported incompatible monetary aggregates for two proposed hard crosswalk settings. This is evidence of a **specific historical model/input mismatch as reported**, not a demonstrated impossibility for every mapping or an independently reproduced production failure.

A stronger profile may become admissible only after relation compilation, conflict-free deterministic closure, **global feasibility**, explicit source and evidence profile/version, and a rule excluding soft benchmark similarities from strict proof. Exploratory mapping output must remain segregated from strict accepted facts until that complete gate passes.

**Negative cases:** one locally consistent mapping edge is mistaken for a globally feasible accounting relationship; a soft proportional bridge is promoted to an official hard equality; a failed historical test is misrepresented as a universal regulation.

## 4. Distinct result surfaces preserve claim strength

The output model benefits from several logically different projections:

| Evidence surface | What it may claim | What it cannot silently claim |
| --- | --- | --- |
| Main regional × OKVED2 × metric grid | Present best accepted publication-level representative, statuses, bounds and links to evidence | Official certainty for a selected latent point |
| Restored primary facts | Subset whose publication values have qualified source-preserving or stronger grounds | Completion of all missing cells |
| Append-only fact ledger | Historical promotions, supersession, method/tier and actual proof lineage | That a superseded weaker proof never existed |
| Latent component grid | Internal component bounds, endpoint support and source relationships | That those components were directly published |
| Partitions/tokens/inheritance | How complete/disjoint source support can localize or promote a fact | Arbitrary copying of a parent's value into an unknown child |
| Solver target/rounding/selection grids | Search scope, strict bound, distortion objective and jointly validated representative choice | Global coverage from a limited search or exact latent truth |
| Conflicts and solver runs | Failure evidence, feasibility and performance/progress diagnostics | Business result correctness merely because a process exited successfully |

The candidate audit inventory includes partition membership, published mass tokens, inheritance events, fixed-point passes, optimization rounds, target bounds, rounding profiles, batch selection decisions, derivations, raw constraints, solver runs and conflicts. A simple workbook can make these extra sheets optional for readability **provided the underlying provenance is available at the level promised to its actual consumer**. The names of individual historical worksheets are not automatically the current file schema.

## 5. Causal diagnostic order and legitimate supersession

For a suspiciously confident reconstructed cell, inspect in order: global feasibility/conflicts; fixed-point convergence and stopping reason; exact fact ledger and assumption tier; token partition/anchor support; inheritance or singleton promotions; target bounds; the `L∞` then `L1` distortion record; joint selection attempt evidence; and solver failure/status/iteration evidence.

A conclusion derived using a weaker premise must retain an equal-or-weaker tier. A genuinely independent stronger proof **may legitimately supersede** a prior weak representative; this is different from silently relabeling the same weak proof as strict. [Semantic promotion firewalls](semantic-promotion-firewalls-and-bounded-reliance.md) and [current solver/evidence architecture](../../current-how/sors-restoration-evidence-and-inference.md) explain the distinction.

## 6. Applicability and tests still needed

This model is specific to bounded reconstruction of rounded source statistics; it is **not** a mandatory full provenance ledger for every Excel import or an accepted corporate-wide registry. A future test should supply exactly versioned official inputs and compare (a) input and observation identities, (b) attempted versus missing periods, (c) deterministic and optional solver modes, (d) conflict and audit surfaces, (e) crosswalk feasibility in each declared profile, and (f) output-tier invariants including the upper-open interval. Real files and installed solver remain required for full validation; all historical trial statements above retain their bounded evidence status.

The publication contains no hyperlink to a historical source or Work file. Any original-line trace belongs to the separate audit corpus; none is necessary to use this scientific description.
