**Scope caveats.** A trusted local single-user client need not own every server-side tenancy behavior, while an admitted shared/Internet-facing host must enforce authority and projection filtering itself. A UI request for cancel is not proof an external effect was cancelled. A generic FileStore can expose unrestricted local paths by design; only a caller that promises workspace confinement must provide the missing authorization boundary. A local close ending a local Run is not a violation of the conditional host durability goal. The source invariant vocabulary is a set of **candidates**, not a prescribed exhaustive database schema or simultaneous release gate for all profiles.
