# Shared semantic ownership

`shared` owns reusable data meaning and exact evidence. `capabilities/model` owns callable definitions, semantic ports and graphs. `capabilities/plan` owns prepared execution instructions. `core` owns technical action implementations, resources, effects and journals. `domains` owns publisher interpretation and scientific rules; `sdk` connects preparation to execution.

The shared layer imports no runtime or domain implementation. Source reference data is read through its explicit owner and recorded by actual content identity. A domain may reuse common settings and methods by direct references; shared contracts contain no publisher dispatch.
