# Domain specifications and continuing series

A domain root exports `DOMAIN`: common reusable settings, continuing table-series records, calculation specifications and products. A monthly publication is one series with dated issues. Different statistical tables retain different records even when a publisher distributes them in one workbook.

A series binds standard command IDs to explicit methods and narrow settings. Shared publication policies, field maps and reference bindings are declared once and reused directly. Domains provide request details, publication selection, physical table selection, interpretation, validation and scientific formulas. They create no operations or execution pools.

Commands declare meaningful input and output types. A fetched response becomes physical evidence before interpretation; validated observations become calculation inputs; views become encoded products before storage. Calculations on individual series differ from bounded application across a table. Coupled restoration uses a shared constraint model and cannot be reduced to independent per-row calculations.
