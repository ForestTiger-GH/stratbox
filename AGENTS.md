# AGENTS.md

## Назначение репозитория

`stratbox` — core-библиотека Strategy Box. Репозиторий владеет доменной бизнес-логикой, нейтральной инфраструктурой, встроенными ресурсами и стабильной границей подключения внешнего runtime/plugin слоя.

Desktop/UI/AppDock surface сюда не входит. Корпоративная runtime-специфика подключается через отдельный plugin-слой.

## Обязательный вход

Перед любой инженерной работой, Research, рефакторингом или изменением архитектурных границ:

1. прочитай `README.md`;
2. прочитай этот файл;
3. открой `_mw/AGENTS.md` — паспорт текущего инженерного рабочего пространства;
4. затем читай только те продуктовые файлы, документацию и тесты, которые нужны для конкретной задачи.

Не восстанавливай текущую архитектуру по именам файлов, истории чатов или старым заметкам, если есть прямой текущий владелец.

## Текущие владельцы

- runtime и библиотечная реализация: `src/stratbox/`;
- упаковка и зависимости: `pyproject.toml`;
- текущая пользовательская и инженерная документация: `README.md` и `docs/`;
- проверочный контур: `tests/` и `scripts/`;
- исследовательская и Work-история: `_mw/`.

`_mw/` хранит развитие, Research и provenance. Размещение материала в `_mw/` не делает его текущей продуктовой истиной и не изменяет код само по себе.

## Границы изменений

Сохраняй core-границу:

- доменные модули не зависят от desktop-приложения;
- GUI и AppDock-артефакты остаются вне этого репозитория;
- корпоративные особенности идут через plugin/runtime boundary;
- surface-репозитории зависят от `stratbox`, а не копируют core внутрь себя.

Предпочитай целевую чистую архитектуру. Не сохраняй слабое решение только ради обратной совместимости, если конкретный внешний контракт явно её не требует.

## Проверки

Для изменений кода используй релевантный минимум проверок и при полном изменении core — полный базовый контур:

```bash
python scripts/check_release_integrity.py
python scripts/check_internal_imports.py
pytest -q
```

Research, заметки и workspace-only изменения не требуют имитации продуктового тестирования, если код и упаковка не менялись.
